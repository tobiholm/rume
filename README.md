# Config Manager

Config Manager is a lightweight Python application for creating, editing and validating configuration files.

## Features

- JSON, YAML and INI support
- Import and export
- Configuration validation
- Backup management
- Statistics
- Local storage

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

## Menu

```
1. View Configurations
2. Create Configuration
3. Validate
4. Export
5. Backup
6. Statistics
7. Exit
```
